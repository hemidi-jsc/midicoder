# Contributing

Thanks for helping improve Midi Coder CLI.

## Ways to contribute

- Improve documentation in `docs/`.
- Add or refine DSL validation rules.
- Enhance stack-specific indexers.
- Extend codegen strategies.

## Development workflow

1. Create a feature branch.
2. Make focused changes with clear commits.
3. Update docs when behavior changes.
4. Submit a pull request with context.

See the `technic/` folder for the official design specs used by the pipeline.
