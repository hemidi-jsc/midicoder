# Đóng góp

Cảm ơn bạn đã đóng góp cho Midi Coder CLI.

## Cách đóng góp

- Cập nhật tài liệu trong `docs/`.
- Cải tiến rule validation cho DSL.
- Nâng cấp indexer theo stack.
- Mở rộng chiến lược codegen.

## Quy trình phát triển

1. Tạo branch tính năng.
2. Thay đổi gọn và rõ ràng.
3. Cập nhật docs khi hành vi thay đổi.
4. Gửi pull request với mô tả đầy đủ.

## Tham khảo thiết kế

Xem thư mục `technic/` để đọc các spec chính thức.
